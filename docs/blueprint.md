# **App Name**: HPITool Chat

## Core Features:

- Chat Interface: Display questions in a conversational, chat-style interface, guiding patients through the OPQRSTUV pain assessment format using Taglish.
- OPQRSTUV Assessment: Utilize the OPQRSTUV format for pain and symptom assessment.
- Copy Answers: Enable users to copy all of their answers into a clipboard at the end of the interview.
- Download Answers: Provide a tool that enables users to download all their answers to a text file at the end of the interview.
- AI-Powered Response Verification: When answering questions about the user's pain/symptoms, if some answers do not conform to conventions or contain obviously irrelevant information, use an AI tool to re-query the user and ensure the user's responses remain factual, clear and objective.

## Style Guidelines:

- Primary color: Soft blue (#7CB9E8) for a calming and professional feel.
- Background color: Light gray (#F0F0F0) for a clean and minimalist design.
- Accent color: Darker blue (#367FA9) for buttons and important UI elements to draw attention.
- Body and headline font: 'Inter', a sans-serif font with a clean and modern look.
- Use simple, professional icons for easy navigation.
- Maintain a clean and organized layout to prevent visual clutter.
- Implement subtle animations for transitions to provide a smooth user experience.
